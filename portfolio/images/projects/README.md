# 📸 Project Images

Questa cartella contiene le immagini personalizzate per i progetti del portfolio.

## 🎯 Come Usare

### 1. Aggiungi le tue foto qui
Salva le tue immagini in questa cartella con nomi descrittivi:
```
solosport-logo.jpg
padel-magazine-01.jpg
dilenarda-sketch.png
rpg-yacht-render-01.jpg
```

### 2. Usa nel Visual Editor
Quando modifichi la gallery di un progetto nell'editor, inserisci l'URL relativo:
```
/images/projects/solosport-logo.jpg
```

### 3. Le foto sono permanenti
Le immagini salvate qui NON verranno mai cancellate finché non le elimini manualmente.

## 💡 Best Practices

- **Nomi file**: usa nomi descrittivi senza spazi (usa `-` o `_`)
  - ✅ `progetto-nome-foto-01.jpg`
  - ❌ `Foto Progetto 01.jpg`

- **Formato**: preferisci JPG per foto, PNG per loghi/illustrazioni con trasparenza

- **Dimensioni**: ottimizza le immagini prima di caricarle
  - Foto gallery: 1200-1600px larghezza
  - Loghi: 800x800px
  - Hero images: 1920px larghezza

- **Organizzazione**: puoi creare sottocartelle per progetto
  ```
  projects/
    solosport/
      logo.jpg
      pattern.jpg
      sketch-01.jpg
    padel-italia/
      cover.jpg
      spread-01.jpg
  ```

## 🔗 URL Paths

Struttura URL per le immagini:

| Posizione File | URL da usare nell'editor |
|----------------|--------------------------|
| `public/images/projects/foto.jpg` | `/images/projects/foto.jpg` |
| `public/images/projects/solosport/logo.jpg` | `/images/projects/solosport/logo.jpg` |

## ⚡ Quick Tips

1. **Backup**: Fai backup regolare di questa cartella
2. **Versioning**: Usa nomi versioned per tenere traccia (es: `logo-v2.jpg`)
3. **Cache**: Se modifichi un'immagine con lo stesso nome, fai hard refresh (`Ctrl+F5`)
4. **Preview**: L'editor mostra preview live delle immagini quando inserisci l'URL
