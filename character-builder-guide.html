Guida operativa completa — struttura cartelle, nomi file, aggiunta varianti

Regola d'oro

Leggi questo prima di tutto

Il sistema funziona in automatico. Devi solo:

1
Creare il PNG con le dimensioni giuste
2
Dargli il nome esatto indicato in questa guida
3
Metterlo nella cartella giusta
4
Ricaricare il browser — il builder lo mostra subito, senza toccare il codice
Dimensione obbligatoria per ogni PNG

2000 × 3000 px

Sfondo trasparente (PNG-24 con canale alpha) · Personaggio centrato orizzontalmente · Piedi ancorati al bordo inferiore

Le cartelle già create nel progetto

Queste cartelle esistono già dentro assets/characters/ — devi solo inserire i PNG al loro interno:

assets/characters/ ├── backgrounds/ ← sfondi scena ├── effects/ ← aure ed effetti (usata sia per Aura Back che Aura Front) ├── base/ ← corpo base / classe del personaggio ├── outfit/ ← vestiti ├── symbols/ ← simboli / emblemi ├── head/ ← testa / elmo ├── eyes/ ← occhi / visiera ├── mouth/ ← bocca / espressione ├── hair/ ← capelli / corna / aureola └── accessories/ ← accessori (spallacci, collare, maschere...)

Attenzione

I nomi file devono essere esattamente come scritti sopra — minuscolo, underscore, nessuno spazio. Se il nome è diverso, il browser non trova il file e la scheda rimane vuota nel builder.

Come aggiungere nuove varianti (es. 100 outfit)

Vuoi aggiungere un nuovo outfit che si chiama "Titan"? Fai questi 2 passi:

Passo 1 — Crea il PNG e mettilo nella cartella

Salva il file come outfit_titan_01.png dentro assets/characters/outfit/

Passo 2 — Aggiungi una riga in character-builder.js

Apri character-builder.js, cerca il blocco id: 'outfit' e aggiungi la riga evidenziata:

// cerca questo blocco nel file: { id: 'outfit', label: 'Outfit', folder: 'outfit', options: [ { id: 'none', label: 'Nessuno', file: null }, { id: 'armor', label: 'Armor', file: 'outfit_armor_01.png' }, { id: 'jacket', label: 'Jacket', file: 'outfit_jacket_01.png' }, { id: 'robe', label: 'Robe', file: 'outfit_robe_01.png' }, { id: 'core', label: 'Core', file: 'outfit_core_01.png' }, { id: 'titan', label: 'Titan', file: 'outfit_titan_01.png' }, ← aggiungi così ] }

Stessa logica per tutte le altre categorie. Il pattern è sempre:

{ id: '[nome_univoco]', label: '[Etichetta nel builder]', file: '[nome_file.png]' }
Convenzione nomi file (rispettala sempre)

[categoria]_[variante]_[numero].png

Esempi corretti:  base_titan_01.png  ·  hair_crown_01.png  ·  outfit_cloak_02.png

Come deve essere posizionato il personaggio dentro al PNG

RegolaCome fare
Canvas fisso Tutti i PNG devono essere 2000×3000 — anche quelli del solo elmo o degli occhi
Centrato orizzontalmente Il personaggio deve avere lo stesso margine a sinistra e a destra
Ancorato in basso I piedi devono toccare (o quasi) il bordo inferiore del canvas
Zona superiore libera La parte sopra la testa rimane trasparente — è normale
Sfondo I background possono riempire tutto il canvas, non servono zone trasparenti
Stessa posizione su tutti i layer Usa un file PSD/AI base e duplicalo — non spostare il personaggio tra un layer e l'altro

Riepilogo operativo — cosa fai ogni volta che hai una nuova foto

1
Crei il PNG 2000×3000, sfondo trasparente, personaggio centrato in basso
2
Lo salvi con il nome corretto nel formato [cat]_[nome]_01.png
3
Lo copi nella cartella giusta dentro assets/characters/
4
Apri character-builder.js e aggiungi una riga nell'array options della categoria
5
Ricarichi il browser — la nuova opzione compare subito nel builder
Ricorda

Il passo 4 (aggiungere la riga nel JS) è necessario solo per far comparire la nuova opzione nella griglia. Se non aggiungi la riga, il file PNG è presente nella cartella ma il builder non lo mostra.
